## 1) نظرة عامة

**مدارك جو** منصة تعليمية أردنية **مجانية 100%**، بدأت فكرة من طالب من جيل 2009 (أكتوبر 2025)، وتجمع كل أدوات الدراسة في مكان واحد:

- مواد دراسية (دروس + كتب + فيديوهات مرفقة)

- مراجعة ختامية تحفظ أخطاء الطالب
- مساعد ذكي اسمه **مُدرك** (معطّل مؤقتاً — التفاصيل بالأسفل)
- **دردشة دراسية** = مجتمع طلابي بحسابات حقيقية وقاعدة بيانات

## 5) قاعدة البيانات (Supabase — تطبيق الدردشة)

مشروع Supabase الرئيسي: **نفس مشروع الإنجاز** (مذكور في `chat/supabase/.temp/linked-project.json`).

### 5.1 الجداول الرئيسية
| الجدول | الوظيفة |
|---|---|
| `profiles` | ملفات المستخدمين (الاسم، الصورة، الجنس `gender`، الحظر، السمات اللونية `theme`) |
| `user_roles` / `role_permissions` | الأدوار (admin/user) والصلاحيات |
| `posts` | المنشورات (نص + `image_urls[]` صور متعددة + قناة `channel`) |
| `comments` / `likes` / `comment_likes` | التفاعلات |
| `notifications` | إشعارات اللايك/التعليق/الرد |
| `post_reports` / `banned_words` | البلاغات وكلمات الحظر |
| `section_locks` | أقفال أقسام الجيل/الجنس |
| `channel_settings` | إعدادات القنوات |
| `study_rounds` + `round_messages` | جولات الدراسة |
| `schedules` / `suggestions` | الجداول والاقتراحات |
| `staff_chat` / `support_messages` | دردشة الإدارة + رسائل الدعم (مع `image_urls[]`) |

### 5.2 القنوات
القنوات: `all` / `male` / `female` / `09` / `10`. الفلترة تتم عبر دالة `can_see_channel()` وراء سياسات RLS.

### 5.3 ملفات SQL (مهم جداً)
| الملف | الوظيفة | متى يعمل؟ |
|---|---|---|
| `chat/databasechatall.sql` (= `database-schema-full.sql`) | **القاعدة المحورة الكاملة**: كل الجداول والدوال والـ triggers والسياسات بالترتيب | على **مشروع جديد** من SQL Editor |
| `chat/chat20.sql` | إضافة القنوات + الجنس + RLS | تطبيق يدوي |
| `chat/chat21.sql` | `channel_settings` + السمات + CHECK constraints | تطبيق يدوي |
| `chat/chat22.sql` | إصلاح قناة "الجميع" + فتح RLS + حذف trigger الجنس | تطبيق يدوي |
| `chat/chat23.sql` | `posts.image_urls[]` (صور متعددة) + حذف نهائي بعد 3 أيام | تطبيق يدوي |
| `chat/chat24.sql` | `support_messages.image_urls[]` + باكت `support-media` | تطبيق يدوي |

> ✅ كل ملفات `chat*.sql` مكتوبة بفواصل آمنة (`IF NOT EXISTS` / `DROP POLICY IF EXISTS`) — تعمل حتى لو شُغّلت مرتين.
> ⚠️ **مهم**: إذا وُجد المشروع ونُقلت عليه من قبل، شغّل `chat22` ثم `chat23` ثم `chat24` بالترتيب — فإن كان المشروع جديداً تماماً فشغّل `databasechatall.sql` أولاً ثم الباقي.

### 5.4 مخازن الملفات (Storage Buckets) — تُنشأ يدوياً باليد

## 7) المساعد الذكي + Cloudflare Worker

- `cloudflare-worker.js`: Worker على Cloudflare يدعو نموذج **Llama** عبر Workers AI، ويهيّئ CORS.
- إعداداته (النموذج، المفتاح الاختياري `MK_KEY`) في أعلى الملف، ورابطه في `js/chatbot.js` داخل `AI.endpoint`.
- النموذج الافتراضي: `@cf/meta/llama-3.1-8b-instruct-fast` — عدّله لـ Llama 3.3 70B إذا لزم (`@cf/meta/llama-3.3-70b-instruct-fp8-fast`).

## 8) تطبيق الدردشة (chat/)

### البنية
```
chat/
├── index.html            ← مخرجات البناء (كنسخة جاهزة للنشر) — لا تعدّلها يدوياً

├── src/
│   ├── main.tsx, App.tsx (المسارات داخل basename="/chat")
│   ├── config/supabase-config.ts  ← رابط + مفتاح Supabase
│   ├── config/sso-config.ts       ← إعدادات SSO مع مشروع الإنجاز
│   ├── contexts/ (AuthContext، PresenceContext، ThemeContext)

└── chat20..chat24.sql + databasechatall.sql  ← تحديثات قاعدة البيانات

### الميزات الرئيسية
- تسجيل دخول إيميل/Google، بروفايل، جنس إلزامي للمستخدم الجديد.
- منشورات بصور متعددة (حتى 4) مع معرض Lightbox، وقنوات (الجميع/شباب/بنات/2009/2010).
- جولات دراسة، اجتماعات مراجعة، إشعارات.
- لوحة إدارة: بلاغات، حظر، كلمات ممنوعة، رسائل دعم (بالصور)، مواضيع دائمة، أدوار.
- سمات لونية لكل مستخدم (نهاري/ليلي/أزرق/وردي).

```

## 10) تسجيل الدخول الموحّد (sso-worker/)

Cloudflare Worker (`sso-worker/sso-worker.js` + `wrangler.toml`):
- وسيط Google OAuth: يعيد المستخدم إلى الدردشة أو الإنجاز بجلسة Supabase صالحة.
- البيانات السرية تُضبط عبر:
```bash
cd sso-worker
npx wrangler secret put GOOGLE_CLIENT_ID
npx wrangler secret put GOOGLE_CLIENT_SECRET
npx wrangler secret put SSO_HMAC_KEY
npx wrangler secret put CHAT_SUPABASE_URL
npx wrangler secret put CHAT_ANON_KEY
npx wrangler secret put ACHIEVEMENT_SUPABASE_URL
npx wrangler secret put ACHIEVEMENT_ANON_KEY
```
- أساسي عند إنشاء مشروع Supabase جديد أو تغيير المفاتيح.

## 13) المشاكل المعروفة والمهام المعلّقة

1. **📌 قاعدة بيانات الدردشة**: تأكد من تطبيق `chat22` ثم `chat23` ثم `chat24` (حسب حالة المشروع). إذا بدأت المشروع من الصفر شغّل `databasechatall.sql` أولاً.
2. **📌 مخازن الملفات**: تأكد من وجود الباكتات الستة في Storage وإلا فشل رفع الصور (بدون كسر الصفحات).
3. **🤖 مُدرك معطّل** (`AI_ENABLED=false` في `js/chatbot.js`) — قرار سابق بسبب ثغرات؛ يعاد التفعيل مستقبلاً.
4. **📚 مواد ناقصة** في بنك الأسئلة: biology unit-04، geography، history.
5. **Google SSO** يعتمد على سكريبت خارجي (Cloudflare) — لو توقف، استخدم تسجيل الإيميل بدلاً منه.
6. `questions/index.json` الرئيسي يذكر 3 مواد فقط — يحتاج تحديثاً كاملاً.
7. **سؤال شائع**: أخطاء `any` في ESLint داخل `chat/` موجودة من الأصل (نمط `(supabase as any)`) — ليست أخطاء تشغيلية.
