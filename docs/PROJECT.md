# مدارك جو — توثيق المشروع

أول منصة تعليمية مجانية من صنع طالب (جيل 2009). منصة موارد دراسية: مواد، امتحانات وزارية، كتب، تحديات سرعة، روابط مختارة.

## البنية

```
index.html            ← الصفحة الرئيسية (اختيار الجيل)
2009/                 ← منصة جيل 2009
  index.html          ← لوحة اختيار التخصص
  engineering.html    ← الهندسة وتكنولوجيا المعلومات
  health.html         ← الطب والعلوم الصحية
  business.html       ← الاقتصاد وإدارة الأعمال
  languages.html      ← العلوم الإنسانية والاجتماعية
2010/index.html       ← منصة جيل 2010 (المواد المشتركة)
exam.html             ← محرك الامتحانات والمراجعة الختامية
coming-soon.html      ← صفحة "قريباً" للأقسام قيد العمل
js/main.js            ← المنطق المشترك (القائمة الجانبية، العارض، النصائح)
css/style.css         ← التنسيقات الكاملة
docs/                 ← التوثيق
serve.js              ← خادم محلي للتطوير (منفذ 8000)
```

## التشغيل محلياً

```bash
node serve.js
# ثم افتح http://localhost:8000
```

## النشر

الموقع منشور على GitHub Pages:

- `origin` → https://github.com/madrekjo/madrekjo.github.io.git (فرع `main`) — النسخة الحية.
- `backup` → https://github.com/madrekjo/madarekjo.git — نسخة احتياطية.
- الرابط الحيّ: https://madrekjo.github.io/

الرفع: `git push origin main` (و `git push backup main` للنسخة الاحتياطية).
