# مدارك جو — توثيق المشروع

أول منصة تعليمية مجانية من صنع طالب (جيل 2009). منصة موارد دراسية: مواد، امتحانات وزارية، كتب، تحديات سرعة، روابط مختارة.

## البنية

```
index.html            ← الصفحة الرئيسية (اختيار الجيل)
2009/                 ← منصة جيل 2009
  index.html          ← لوحة اختيار التخصص
  engineering.html    ← الهندسة وتكنولوجيا المعلومات
  health.html         ← الطب والعلوم الصحية
  business.html       ← الاقتصاد وإدارة الأعمال
  languages.html      ← العلوم الإنسانية والاجتماعية
2010/index.html       ← منصة جيل 2010 (المواد المشتركة)
ask/                  ← قسم "اكتب سؤالك" (تطبيق React مستقل)
teacher-files/        ← قسم "ملفات المعلمين" (تطبيق React مستقل)
exam.html             ← محرك الامتحانات والمراجعة الختامية
coming-soon.html      ← صفحة "قريباً" للأقسام قيد العمل
js/main.js            ← المنطق المشترك (القائمة الجانبية، العارض، النصائح)
css/style.css         ← التنسيقات الكاملة
docs/                 ← التوثيق
serve.js              ← خادم محلي للتطوير (منفذ 8000)
```

## التشغيل محلياً

```bash
node serve.js
# ثم افتح http://localhost:8000
```

## قسم اكتب سؤالك

**الرابط الحي**: https://madrekjo.github.io/ask/

### شو هو؟
قسم تفاعلي يسمح لأي زائر بكتابة سؤال دراسي ومشاركته مع جميع الطلاب بشكل بطاقة جذابة. كل طالب مهما كان حقله أو جيله يقدر يطرح سؤاله بلا خجل، والأسئلة تترتب كريلز تفاعلية يتصفحها الجميع.

### ليش موجود؟
هدفه الأساسي بناء **مكتبة أسئلة مشتركة** يبنيها الطلاب أنفسهم. كل سؤال يُنشر يثري المحتوى التعليمي للمنصة، وكل إجابة صحيحة تُسجّل في ملف الشخص. هيك القسم يكبر تلقائياً مع كل طالب يسأل.

### كيف يشتغل تقنياً؟
- **واجهة**: تطبيق React مستقل (مجلد `قسم اكتب سؤالك/`) يُبنى بـ Vite ويُنشر في `ask/`.
- **قاعدة البيانات**: Supabase (مشروع `khqhlznlummkjdpssbds`) — الجداول:
  - `profiles` — بروفايلات المستخدمين (يُنشأ تلقائياً عند التسجيل)
  - `questions` — الأسئلة مع الخيارات والإجابة الصحيحة
  - `likes` — لايك لكل سؤال
  - `saves` — المحفوظات لكل مستخدم
  - `answer_attempts` — محاولات الإجابة (تتكرر عند إعادة الحل)
  - `question_stats` — عدّادات موحّدة (لايك + محاولات)
- **الحسابات**: دخول ضيف مجهول (Anonymous sign-in) — لا يتطلب إيميل أو كلمة مرور.
- **صورة البطاقة**: رسم Canvas يُولّد صورة JPG للسؤال (مرفقة مع البطاقة عند المشاركة) — مدارك جو في الأعلى، السؤال في الوسط، واسم القسم في الأسفل.
- **ال Syrians**: شاشة شرح تظهر مرة واحدة لكل زائر تشرح طبيعة القسم والهدف والنمط.

### النشر
1. `npm run build` داخل `قسم اكتب سؤالك/`
2. نسخ `dist/*` إلى `ask/` في جذر المستودع
3. `git add ask` ثم `git push origin main`

ملاحظة: حسابات الضيف (Anonymous) يجب تفعيلها يدوياً من لوحة Supabase → Authentication → Providers → Anonymous → ON.

## قسم ملفات المعلمين

**الرابط الحي**: https://madrekjo.github.io/teacher-files/

### شو هو؟
قسم يعرض ملفات ومحتوى المعلمين للطلاب — لامتحانات سابقة، ملخصات، أو أي مادة مساعدة يقدّمها المعلمون.

### ليش موجود؟
الطلاب يحتاجون محتوى المعلمين أحياناً تكون أفضل تلخيص من أي مصدر آخر. القسم يوفّر مكاناً واحداً يرجعون إليه لكل ما يرفعه معلمهم، ويوفر للطلاب التصفح_without روابط خارجية.

### كيف يشتغل تقنياً؟
- **واجهة**: تطبيق React مستقل (مجلد `teacher-files/`) يُبنى بـ Vite ويُنشر في `teacher-files/`.
- **القائمة الجانبية**: الرمز `📂` يظهر في كل قسم (2009 و 2010) كأول عنصر مع شارة "جديد" حمراء.
- **شاشة الشرح**: قبل الدخول مباشرة تظهر قصة توضيحية تشرح محتوى القسم وأهميته.
- **النشر**: خطوات مماثلة لقسم الأسئلة — `npm run build` ثم نسخ إلى `teacher-files/`.
