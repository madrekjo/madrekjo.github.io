# سجل مشاكل قاعدة البيانات — DataBase Problem Log

هذا المجلد يمثّل **سجل مشاكل قاعدة البيانات** الخاص بموقع **مدارك جو**،
مفصولاً حسب التطبيق، بأسماء مجلدات إنجليزية.
يمثل هذا المجلد القسم المطلوب من سجل المشاكل (docs/problem-logs).

## البنية
```
database/
├── chat/            سجل مشاكل قاعدة بيانات تطبيق الدردشة
├── achievement/     سجل مشاكل قاعدة بيانات تطبيق النجاحات
└── anon/            سجل مشاكل قاعدة بيانات قسم "أنا مجهول"
```

## الغرض
توثيق المشاكل المتعلقة بـقاعدة البيانات (استعلامات، استطلاع، triggers،
سياسات RLS، مؤشرات، أداء) لكل تطبيق، مع طريقة الحل، لسهولة الرجوع
إليها ومشاركتها.
