# 📚 مكتبة مدارك — نسخة تجريبية مستقلة

قسم «مكتبة مدارك» داخل موقع مدارك جو — **نسخة تجريبية محلية فقط**.
لا يُنشر، ولا يتصل بأي خادم، ولا يربط بـ Supabase في هذه المرحلة.

## التشغيل محلياً

```bash
# من جذر المشروع
node serve.js
```

ثم افتح في المتصفح:

```
http://localhost:8000/maktabet-madarek/
```

## ماذا يمكنك تجربته

1. **التصفح**: البحث الفوري (الاسم/الوصف)، الفلاتر (السنة/المادة/الفصل/النوع)،
   ترتيب الأحدث والأكثر تحميلاً، وفتح تفاصيل الملف.
2. **الرفع**: نافذة «ارفع ملفك» — يقبل PDF و JPG و PNG حتى 10MB فقط، مع شريط
   تقدم تجريبي وتحقق من الحقول، والمُرفق يدخل «قيد المراجعة» تلقائياً.
3. **الإدارة**: زر الدرع 🛡️ أعلى الصفحة → أدخل رمز الإدارة التجريبي **`3330116`**:
   - اعتماد / رفض / حذف (مع تأكيد) / إعادة للمراجعة.
   - عرض الملفات المعلّقة والمقبولة والمرفوضة مع بحث داخلي وإحصائيات.
   - زر «↺ إعادة التهيئة» لإرجاع البيانات التجريبية الأصلية.
   - زر خروج من وضع الإدارة.

## ملف قاعدة البيانات (Supabase)

- الملف: `supabase/migrations/20261012_maktabet_library.sql` داخل هذا المجلد.
- ينشئ: جدول الإعدادات والملفات والبلاغات، سياسات RLS، مخزن الملفات
  `maktabet-library-files`، دالات الأدمن والإدراج وتغيير الحالة والحذف
  وعدّاد التنزيلات، وحارس حجم الملف **10MB** على مستوى التخزين.
- رمز الأدمن `3330116` مخزَّن في جدول الإعدادات (يُغيّر منه) وليس في كود الموقع.
- **التنفيذ يدوي** من Supabase Dashboard → Database → SQL Editor، ثم التفعيل:
  `UPDATE public.maktabet_library_settings SET library_enabled = true WHERE id = 1;`

## بيانات تجريبية

- 14 ملفاً وصفياً تجريبياً (موزعة بين معتمد / قيد المراجعة / مرفوض).
- عند الضغط على «تنزيل» تولَّد ملفات **نصية تجريبية** توضح أنها وهمية
  (لا يوجد ملف حقيقي على أي خادم).
- المحتوى الحقيقي للملفات المرفوعة يحفظ في **ذاكرة الجلسة فقط** ولا يبقى
  بعد تحديث الصفحة (حمايةً لمحدودية LocalStorage).
- الحالة والعدّادات تُحفظ في LocalStorage وتبقى بعد تحديث الصفحة
  حتى تعاد تهيئتها من لوحة الإدارة.

## ما هو تجريبي وما يحتاج خادماً حقيقياً

| الميزة | الحالة في الواجهة | ما تحتاجه لاحقاً |
|---|---|---|
| رفع الملفات وتخزينها | وصفية فقط + ذاكرة جلسة | تخزين ملفات (مثال: Supabase Storage) |
| حالة الملفات (معتمد/مرفوض) | LocalStorage | جداول في قاعدة البيانات |
| رمز الإدارة `3330116` | تحقق محلي غير آمن | مصادقة حقيقية (دالة آمنة + صلاحيات) |
| عدّاد التنزيلات | عدّاد محلي | RPC آتومي في القاعدة |
| البحث والتصفية | يعمل فعلياً محلياً | يبقى كما هو لكن من قاعدة البيانات |

## البنية البرمجية (جاهزة للربط بـ Supabase)

يوجد **طبقة بيانات معزولة** في `js/store.js` عليها علامة
`TODO: Supabase` عند كل نقطة ستدخل في الربط المستقبلي
(جلب الملفات، الإدراج، التحديث، الحذف، الرفع). الواجهة لا تتكلم
مع التخزين مباشرة، لذا يمكن استبدال LocalStorage بـ Supabase
دون تعديل ملفات الواجهة.

## الملفات

- `index.html` — صفحة المكتبة الكاملة (واجهة + نوافذ + لوحة إدارة).
- `css/library.css` — الأنماط بهوية مدارك جو (أخضر داكن + فيروزي + أبيض، RTL).
- `js/config.js` — الإعدادات والتصنيفات وقيود الرفع (10MB) ورمز الإدارة.
- `js/seed.js` — البيانات التجريبية الأصلية (14 ملفاً).
- `js/store.js` — طبقة البيانات (LocalStorage + ذاكرة الجلسة).
- `js/app.js` — منطق الواجهة والتفاعل.
- `supabase/migrations/20261012_maktabet_library.sql` — جاهز للربط بقاعدة Supabase.

> ⚠️ لا يُنشر هذا القسم حتى توافق على التصميم ونجهّز قاعدة البيانات الحقيقية.
