# 🌙 أجر وثواب للجميع — مدارك جو

صفحة قرآن وحديث يومياً للجميع، تابعة لموقع **مدارك جو**.

## ✨ المميزات

- 📖 **القرآن الكريم**: صفحة يومية من القرآن الكريم تُفتح تلقائياً حسب اليوم.
- 🎧 **التلاوة الصوتية**: استمع لآيات الصفحة مع مجموعة من القرّاء (تلاوة آية بآية من everyayah.com).
- ✅ **حديث اليوم**: معرض من ٣٠ حديثاً من أحاديث رسول الله ﷺ مع شرح الشيخ ابن باز رحمه الله.
- 📅 **الجدول الزمني**: يبدأ من ٦ أبريل ٢٠٢٦ بمعدل ١٥ آية يومياً من سورة البقرة آية ٢٥٨ وإلى نهاية المصحف.

## 🚀 التشغيل

```bash
npm install
npm run dev
```

## 🏗️ البناء للإنتاج

```bash
npm run build
npm run preview
```

## 📁 البنية

- `src/data/quranPages.ts` — الصفحات اليومية وجدول آيات السور وقائمة القرّاء.
- `src/data/hadiths.ts` — أحاديث اليوم الثلاثون مع شروحها.
- `src/components/QuranSection.tsx` — القسم القرآني مع المشغل الصوتي.
- `src/components/HadithSection.tsx` — قسم حديث اليوم.
- `src/pages/Index.tsx` — الصفحة الرئيسية.

- نسخة **ثابتة** مستقلّة من القسم مدمجة داخل موقع مدارك جو في `ajr.html`.
