## 🧠 مُدرك — مساعدنا الذكي

مُدرك ليس شات عادي — هو **رفيق دراسة** يفهم أين أنت في المنصة:

- 🎯 **يعرف موقعك** من الصفحة (مسارك أو جيلك) ولا يخمّن من كلامك.
- 🗣️ **يجاوب بلغتك** — عربي أو إنجليزي.
- 🧠 **يتذكر سياق المحادثة** (آخر 6 تبادلات).
- 📖 **يشرح الدروس** بمعرفة عامة مبسطة.
- 🧭 **يرشدك لكل قسم** بأزرار تنقل ذهبية تفتح الصفحة مباشرة.
- 🛟 **قسم مساعدات كامل** بأقسامه الثلاثة (عن المنصة / الدراسة / المساعدات).

> مدعوم بـ **Cloudflare Workers AI** — نقطة واحدة تربطه بذكاء Llama 3.3 70B.
